# 已知差异

## 已知差异

- **早期 Ogg 数值精度**：保留现代 libvorbis 解码。在既有两组早期 Sound 的六个严格比较用例中，
  PCM 内容去重后的两对输出共有 16384 个 int16 单元，其中 11 个各相差 1，理论上并无大碍。
- **来源不明的环境文件**：保留一份旧输入尾部多一个字节的未定边界。
- **未明 params 字段**：部分字段的结构读取及原值保留已确认，完整业务含义尚未确认。
